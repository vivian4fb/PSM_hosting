# Changelog

## 0.1.0 (in progress, September 2026)
- Python package `psmgrating`: paper conventions, four two-wave models (PSM, PSM*, Kogelnik, TCWT), RCWA reference, chain-matrix solver for the exactly unslanted grating, figures of merit, figure presets.
- Test suite: Bragg-resonance limits, closed forms against a matrix-exponential oracle, convention guards, RCWA energy conservation, the paper's printed figure values.
